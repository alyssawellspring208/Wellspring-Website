HOW TO UPLOAD
1. Unzip this file on your computer. Do not upload the ZIP itself.
2. Open the UPLOAD_TO_GITHUB folder. It contains two paths:
     .github/workflows/wellspring-public-site-update.yml
     _posts/2026-11-16-mens-health-after-40.md
3. In your existing GitHub repository, use Add file > Upload files.
   Upload the contents of UPLOAD_TO_GITHUB, preserving the paths above.
   If you use a Mac, press Command + Shift + . in Finder to show .github.
4. Commit the uploaded files to the main branch.
5. If GitHub Actions are enabled and allowed to write to the repository,
   the workflow will update existing pages and create a commit.
   Check the Actions tab and then verify your live website.
