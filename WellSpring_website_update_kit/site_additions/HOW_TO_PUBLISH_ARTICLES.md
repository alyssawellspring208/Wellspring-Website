# WellSpring Journal publishing

This project uses the existing GitHub Pages website and Jekyll's built-in Markdown post support.

The article list on `journal/index.html` automatically includes any published posts in `_posts/`.
The individual article design is in `_layouts/journal_post.html`.

## Using the editor

1. Open https://app.pagescms.org/ and sign in with the GitHub account that owns the WellSpring repository.
2. Authorize the Pages CMS GitHub App for `Wellspring-Website`.
3. Open the **WellSpring Articles** collection, choose **New**, and fill in the article title, publication date, author name, category, summary, and body.
4. Save. Pages CMS commits the Markdown content to GitHub. GitHub Pages then rebuilds the website.

For articles written by Alyssa, use **Alyssa Blackson** as the author name. Use the appropriate person's name for articles written by other contributors. No other organizational affiliation is included in this setup.

Clinical content should be reviewed by a WellSpring licensed clinician before public publication.
